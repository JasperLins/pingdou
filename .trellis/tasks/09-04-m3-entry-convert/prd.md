# M3 三入口与生成类型：新建路径+转图流程

## Goal

实现创作入口与图片转图纸全流程：新建对话框入口路径（按父任务决议：自由创作/导入作品合并为一入口 + 图片转图独立入口）、生成类型预设（Q版/标准/写真）与转换参数联动、五步转图工作流（上传→选类型→转换参数→实时对照→进编辑器精修）。

## Requirements

- 新建对话框（NewDialog）：两条路径——"空白画布 / 导入我的作品"（合并入口：导入即把图片挂到参考层后进编辑器）与"从图片转图"（进转换流程）；规格/板型/品牌三选；空画布亦可在编辑器内随时发起转换。
- 生成类型预设（文档 §4.3.3，参数均为可覆盖起点）：
  - Q版：目标 20×20–29×29、色数默认 16（targetColors 参数落地，UI 可调可关）、卡通风格
  - 标准：29×29–58×58、色数由素材定、卡通风格
  - 写真：58×58–104×104、色数不限制、平滑风格
- 转换流程（ImportDialog）：拖拽/选择上传（PNG/JPG/WebP ≤10MB，透明背景支持，上传前 Canvas 预压缩最长边 2048）；预置参数可调（目标尺寸 29/52/58/87/104 档位+自定义 7–104 正方形、品牌、平滑/卡通、目标色数、亮度/对比度/饱和度、移除纯色背景容差）；左侧原图右侧结果实时对照；结果进编辑器、原图挂参考层。
- 边界提示：低分辨率/近纯色提示更换；Q版+写实照片提示改用写真或裁剪；>104×104 拒绝并说明（P2 大图承接）。
- 前置裁剪步骤（pixel-beads 调研采纳，报告见 m2-editor/research-pixel-beads.md）：上传后进入裁剪——8 向手柄裁剪框 + 主体缩放滑杆 + 实时"预计约 N 颗宽"反馈（文档 §4.3.5"裁剪主体"的 UI 化）。
- 源图类型三选（pixel-beads 调研采纳）：普通图片 / 像素画 / 拼豆图纸；像素画与已有图纸按格直映最近色号（不走降采样，避免二次失真）。
- targetColors 快捷档位（pixel-beads 调研采纳）：参数面板提供 24/48/72/96/120/不限 档位 chips（对齐 MARD 色数档位习惯，与自由输入并存）。
- 埋点留位：import_convert 事件带上生成类型/尺寸/品牌/风格/是否去背景。

## Acceptance Criteria

- [ ] 新建两条路径行为正确：导入作品默认进空白画布+参考层挂图；转图默认进转换流程
- [ ] 三种生成类型的预置参数（尺寸区间/风格/色数建议）联动正确且全部可被用户覆盖
- [ ] Q版产出 ≤29×29 且 targetColors=16 生效（色号数 ≤16，UI 可调可关）；写真 104×104 全尺寸可转
- [ ] 转换对照视图实时更新；转换结果与原图进编辑器后参考层可用
- [ ] 全部边界提示按清单触发
- [ ] 像素画/图纸源图直映正确（产出格数与源图网格一致，色号为最近色映射）；裁剪框、主体缩放、豆宽预估、targetColors 档位 chips 可用
