# 技术设计 · M3 三入口与生成类型

## 1. 转换流状态机（ImportDialog 内部）

```text
idle（选择来源）
  → crop（裁剪+主体缩放+源图类型三选，预计豆宽实时反馈）
  → config（生成类型 + 参数面板 + 实时对照预览）
  → converting（Worker 执行，进度态）
  → done（结果预览 → [进编辑器精修] / [返回调整]）
任意态可回退上一步；取消关闭并清理对象 URL。
```

- 源图类型三选（普通图片 / 像素画 / 拼豆图纸）：像素画与图纸走**按格直映**（识别源图像素网格尺度 → 逐格最近色映射，跳过降采样与代表色阶段；实现放 lib/converter 的直映入口或独立函数，算法纯函数可测）
- 裁剪：8 向手柄矩形（拖拽 + 键盘方向键微调）；主体缩放滑杆（裁剪区内 push/pull，重新计算目标网格映射）；"预计约 N 颗宽"= 目标宽度档位 × 裁剪框宽占比
- 直开导入（无对话框路径）：编辑器内"从图片转图"入口 → 同一 ImportDialog

## 2. 组件清单

```text
src/components/editor/ImportDialog.tsx     主对话框（状态机宿主，Drawer 或大 Dialog）
  CropStep.tsx                             裁剪 + 主体缩放 + 类型三选 + 豆宽预估
  ConfigStep.tsx                           生成类型卡（Q版/标准/写真）+ 参数面板 + 对照预览
  CompareView.tsx                          左原图 / 右结果实时对照（复用转换 Worker 增量重跑，150ms 防抖）
src/store/convert.ts                       转换会话态（步骤/源图/裁剪/参数/结果），不入 project store
NewDialog 扩展                              "从图片转图"路径入口
Studio 顶栏                                 "转图"按钮（空画布随时可发起，对齐决议：入口只是起点）
```

## 3. 参数面板（ConfigStep）

- 生成类型卡三张（一句话心智 + 默认参数联动）：Q版（20–29 档 / targetColors 默认 16 / 卡通）、标准（29–58 / 不限 / 卡通）、写真（58–104 / 不限 / 平滑）
- 目标尺寸：29/52/58/87/104 档位 chips + 自定义（7–104 正方形输入）
- targetColors：24/48/72/96/120/不限 档位 chips + 自由数字输入（0=不限）
- 品牌（跟随工程品牌锁定，转换不可换——如需换走品牌切换映射）、平滑/卡通、亮度/对比度/饱和度、移除纯色背景容差
- 全部参数可覆盖生成类型预设（"类型是起点不是约束"）

## 4. Worker 接线

- 复用 lib/converterClient（m1 已建 Promise 封装；本任务首次真实浏览器接线）
- 参数变更 → CompareView 防抖 150ms → 增量重跑（量化缓存命中时 <200ms）；104×104 目标 ≤2s
- 上传预压缩：Canvas 最长边 2048（m1 管线已有约束，UI 层执行）

## 5. 边界与提示（对齐 prd/需求 §4.3.5）

低分辨率 <100×100、近纯色、>104×104 拒绝（P2 承接文案）、Q版+写实照片建议改写真——用 lib/converter 错误码驱动 toast/inline 提示；埋点 analytics.track('import_convert', {...}) 留位。
