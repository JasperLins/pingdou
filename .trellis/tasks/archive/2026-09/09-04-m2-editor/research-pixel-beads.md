# 竞品调研 · Pixel-Beads（pixel-beads.com · 拼豆艺术）

> 调研目的：与 Beadify 报告互补，覆盖功能重叠度最高的中文竞品。方法：登录态实测（用户账号），注入测试图跑通 上传→裁剪→类型→生成→编辑→导出面板 全流程，另读账户/社区页。调研日期 2026-09-04。对照基线：本任务 prd 与 features.md 当前定稿。

## 1. 站点全景与商业模式

- 中文站（多语言切换），Google Ads 广告变现（页面嵌入 AdSense），有 Android 测试版（Google Play）
- 产品矩阵：**图片转像素画**（通用工具）/ **拼豆图纸生成器**（重点）/ 手动绘制编辑器（/zh/perler-bead-art）/ **图纸库**（主题拼豆，UGC）/ 作品展示 / 账户
- **免费开放策略："不登录仍可使用生成器、编辑器、分析和导出；账户只增加云端连续性"**——与 Beadify（导出强制登录+每日配额）相反，与我们 P0 口径一致
- 账户体系：我的项目（云副本）/ 公开投稿（**待审核/已通过/未通过**三态审核流）/ 收藏；"发布到图纸库"从编辑器一键发起——UGC 供给 → 图纸库 → SEO 流量的内容循环

## 2. 图片转像素画（通用转换器，非拼豆专用）

- 上传/拖拽/**剪贴板粘贴**，PNG/JPG/WebP/GIF/SVG ≤20MB；"你的图片不会离开当前设备"（纯本地）
- 像素尺寸 1–100 滑杆、亮度/对比度/饱和度
- 7 套游戏调色板（Pico-8/Lost Century/Game Boy/Sunset 8/Twilight 5/Hollow/预览16色）+ **从图片提取调色板** + 自定义创建 + **Lospec.com / PixilArt.com 调色板导入**（URL 或 HEX 列表）
- 下载：小图 PNG（真实像素网格）/ 大图 PNG（同结果放大）双尺寸
- 示例图一键载入（标注像素尺寸与调色板）；SEO 内容极重（13 组真实转换对照、按用途分型的长文）

## 3. 拼豆图纸生成器（重点实测）

### 3.1 前置流：上传 → 裁剪 → 类型 → 生成

- **裁剪对话框**：8 向手柄裁剪框（方向键微调）+ **主体缩放滑杆**（在裁剪区内推近拉远主体）+ 实时反馈"**预计约 52 颗拼豆宽**"
- **源图类型三选：普通图片 / 像素画 / 拼豆图纸**——源图本身是像素画或已有图纸时按格直映（1:1 映射色号），不走降采样，避免二次失真
- 取色模式（随类型变化）：主色取色（默认）/均匀取色/快速取色/柔和配色/像素细节/精细匹配
- 确认按钮文案跟随类型（"按照片生成"）

### 3.2 生成参数面板（左 dock，可拖动/隐藏）

- **图案细节预设**：细节优先（默认）/精简·Beta/标准·Beta/细腻·Beta/平滑自然——概念同我们的"生成类型=选作品的样子"
- 图纸宽度：52 颗 / 104 颗 / 自定义；**高度按图片比例自动计算，单边最大 200 颗（支持非方形图纸）**
- 网格大小 5mm/2.6mm；辅助网格设置：**每 5 格辅助线、每 10 格大格线，缩小时自动简化**；坐标数字开关
- 拼豆品牌：Perler/Hama/Artkal/**MARD（默认选中）**/Artkal M-2.6mm——本土品牌优先的直接证据
- **MARD 分类（色数档位）**：24/48/72/96/120/144/168/192/216/**221（默认）**/264/所有 MARD(291)——色数档位作为色板子集选择器（对应我们需求 §4.5.3"24 色档位"概念 + 已定的 targetColors 参数）
- 修改参数后需点"重新生成图纸"（同 Beadify 的显式应用）

### 3.3 编辑器

| 区块 | 内容 |
| --- | --- |
| 工具 | 画笔/橡皮擦/吸色器/**原图取色（在原图上放信标→自动找最近拼豆色号）**；绘制范围仅 单格/矩形填充。**无油漆桶、直线、椭圆、选区** |
| 快捷颜色 | 最近使用色一排 + 当前色大色块（A1）+ 完整色板入口 |
| 顶栏 | 撤销/重做/**镜像**（整图翻转）/**颜色调整** |
| 颜色调整 | **删除颜色 / 替换颜色 双页签**；支持**多选批量删色**、已用色搜索 + 排序、色卡带颗数徽标 |
| 图层 | **绘制层 + 板子层**（生成图纸），各带显隐开关与**不透明度滑杆 0–100%**——把板子层调淡可检查手改 |
| 对称轴 | 关闭/**纵向**/横向；"一侧绘制或擦除，另一侧同步"；**轴位置显示（26 格）可拖动 + 居中按钮** |
| 用量 | "已使用 5 种颜色 / 共 2704 颗"；**已使用/全部 221 页签**；**点击某色 → 画布高亮该色全部格子** |
| 导出 | 下载 PNG / 下载 PDF / 图纸设置（**网格/方珠**渲染样式）/ 保存到我的项目 / **发布到图纸库** / Android 版入口 |
| 画布 | 缩放滑杆+百分比；坐标标注 1/5/10…52；网格为 ARIA grid（可访问性做得好） |

### 3.4 与我们规划对照

**它比我们强（吸收点）**：源图类型识别与直映；裁剪+主体缩放+预计豆宽前置；对称轴规格完整（轴可拖）；颜色高亮定位；批量删色与已用色搜索；板子层不透明度；非方形到 200；MARD 档位全梯度；辅助网格自动简化；投稿审核流。

**我们比它强（保持优势）**：工具集（我们有油漆桶连片填充/直线/矩形/椭圆/吸管，它只有画笔/橡皮/矩形填充）；**烫染效果预览独家**；参考层透写/对照（它无参考层概念）；CIEDE2000 跨品牌映射（它换品牌需重新生成）；BOM CSV 采购对账（它用量面板无导出）；无色数限制口径 + 特殊效果色管理；工程 JSON 可迁移；30s 自动保存（它仅手动"保存到我的项目"）。
