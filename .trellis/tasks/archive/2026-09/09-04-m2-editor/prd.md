# M2 编辑器 MVP：画布/工具/色板/用量/撤销

## Goal

实现编辑器核心：CanvasStage 画布（绘制工具/缩放平移/参考层）、ToolRail 工具栏、PalettePanel 色板面板、StatsPanel 用量与 BOM 面板、撤销重做、自动保存、新建项目对话框。达成 104×104 网格绘制响应 ≤100ms。

## Requirements

- 绘制工具（文档 §4.4.1 P0 项）：画笔、橡皮、油漆桶（同色连片填充）、直线、矩形、椭圆、吸管（Alt+点击）。
- 视图：滚轮缩放、平移（空格拖拽）、适应窗口、网格线显隐、高倍率色号首字母显示。
- 撤销重做：100 步历史（Ctrl+Z / Ctrl+Shift+Z），即时响应。
- 全局换色（某色号全部替换为当前选中色）与清除颜色（一键清某色，去孤立碎色）——StatsPanel 内操作。
- 色板操作：按色号/名称搜索、色系分组、最近使用。
- 参考层：置于网格下方（透写）或上方（对照），不透明度 0–100% 可调，可开关。
- 新建项目：规格（5mm/2.6mm）、板型（档位 29/52/58/87/104 + 自定义 7–104 正方形；非正方形 P1 再开，2026-09-04 定案）、品牌色卡三选，创建后品牌锁定。
- 工程：localStorage 30s 自动保存 + 工程 JSON 导入导出恢复（调 lib/storage；参考图走 IndexedDB 分层存储，2026-09-04 定案）。
- 快捷键体系：B 画笔 / E 橡皮 / G 油漆桶 / I 吸管 / [ ] 笔刷大小 / 空格平移。
- zustand 状态设计：project store（cells 持久数据）与 editor store（视图/工具态）分离；撤销栈不可变更新。
- 跨品牌切换（2026-09-04 定案：一键映射+角标复查）：一键按 CIEDE2000 全量自动映射已用色号，被映射格显示角标，支持一键撤销；映射明细面板可逐格修改。
- 一键去噪（Beadify 调研采纳，报告见本目录 research-beadify.md）：lib 纯函数清理孤立碎色（连通域面积阈值可配），用量面板入口。
- 两色互换 Swap Colors：一键把色号 A 与 B 全部互换（与全局换色同面板）。
- 常用色快捷行：PalettePanel 顶部固定常用色一排 + 当前选中色大色块（Current Color）。
- 物理规格反馈：状态栏与新建对话框实时显示物理尺寸（5mm/2.6mm 换算 cm）与板覆盖数；规格↔板型联动（如 2.6mm 时禁用 5mm 板并提示原因）。
- 导出前自检 Readiness（Beadify 调研第二轮采纳，报告 §5.5-B）：StatsPanel 顶部自检区——色号有效、无孤立碎色、无待确认品牌映射、BOM 统计完整；问题清单化提示，全部通过显示无问题。
- 颜色高亮定位（pixel-beads 调研采纳，报告见本目录 research-pixel-beads.md）：用量面板点击某色，画布高亮该色全部格子。
- 批量删色与已用色搜索（pixel-beads 调研采纳）：全局换色/清除颜色交互支持多选批量删色、已用色搜索与排序、色卡带颗数徽标。
- 辅助网格自动简化（pixel-beads 调研采纳）：画布缩小时辅助网格线自动简化，减少视觉噪声。

## Acceptance Criteria

- [ ] 104×104 网格绘制响应 ≤100ms，滚动缩放平移流畅
- [ ] 七种工具行为正确，油漆桶连片填充正确
- [ ] 100 步撤销重做即时；30s 自动保存不阻塞绘制
- [ ] 快捷键全表可用，与主流工具肌肉记忆一致
- [ ] 新建→绘制→换色→保存→重开恢复 全流程通过
- [ ] 一键去噪生效（孤立碎色按连通域阈值清理）；两色互换、常用色快捷行、cm 尺寸与板数显示、规格↔板型联动提示全部可用
- [ ] 导出前自检区可用（问题清单化提示，全部通过时显示无问题）
- [ ] 颜色高亮定位、批量删色、已用色搜索/排序、辅助网格自动简化可用
- [ ] `tsc --noEmit` 零错误
