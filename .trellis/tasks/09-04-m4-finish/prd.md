# M4 烫染预览集成：滤镜面板 F1-F4+效果封面

## Goal

实现滤镜式烫染效果预览（文档 §4.6）：效果面板（F1）、画布实时渲染（F2）、强度调节（F3）、对比查看（F4）、finish 字段持久化与效果封面（F6）。渲染管线在本工作区从零实现（无原型可平移），Canvas 2D 主路线，Worker 执行。

## Requirements

- 渲染管线（lib 层纯函数，Worker 调用）：工程数据(cells+色板) → 熔融基底（豆格色块+十字缝+中孔痕+熔融模糊）→ 高度场 → 中心差分法线 → 漫反射+高光 → 烫法特效层 → 色调映射（强度 0–100 同系数插值）。
- 6 种预设（父任务决议 2）：normal 正常烫 / towel 毛巾烫 / glitter 格利特烫 / sequin 亮片烫 / waffle 华夫格烫 / loofah 搓澡巾烫；分组 经典/质感/闪亮；视觉基线参考文档 §4.6.3（实现参考非规格，以实物照片对照验收：肉眼可区分、贴近特征）。
- F1 面板：预设缩略图列表（用当前作品低分辨率渲染）、烫法名；面板打开逐个替换缩略图不阻塞。
- F2 画布：选定后画布即时切换烫后效果，隐藏网格与色号标注，Esc 返回编辑视图；**零副作用**——渲染层属性，不修改 cells。
- F3 强度：0–100% 滑杆，停顿 150ms 后触发重渲染，完成 ≤1s。
- F4 对比：按住对比按钮或空格，瞬时切回平面图纸。
- F6 持久化：finish{preset,intensity} 写入工程 JSON（§4.8 schema）；保存动作本身 ≤500ms 返回，效果封面异步生成（全分辨率 PNG），失败不阻塞保存、降级用平面图纸图；画布修改后缩略图标记过期重算。
- 性能（文档 §4.6.6）：单预设切换 ≤1s 渲染期不冻结 UI；面板首开全预设缩略图 ≤3s；>100×100 或低端设备自动降预览分辨率（导出不受影响）。

## Acceptance Criteria

- [ ] 6 预设肉眼可区分且贴近对应实物特征（对照 .uploads 工艺参考图/实物照片，进入本任务的验收素材需先补齐）
- [ ] 单预设切换 ≤1s、强度拖动防抖 150ms 后 ≤1s、全程 UI 不冻结（Worker/分片验证）
- [ ] Esc/空格交互正确，视图切换零副作用（cells 逐格比对不变）
- [ ] finish 持久化往返一致；效果封面异步生成、失败降级路径可复现
- [ ] 缩略图过期重算逻辑正确
