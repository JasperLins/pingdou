# M6 P0 质量验收：样图复刻 Q1-Q6+性能实测

## Goal

对 M0–M5 交付物做端到端质量验收：用真实素材跑样图复刻全流程、逐项核验 Q1–Q6、实测性能指标、浏览器兼容抽查，产出 P0 验收报告并给出 M7 批次的优先级建议。

## Requirements

- 样图复刻：取与用户样图同类素材（动漫角色/卡通插画，55×63 规格或同类、MARD 色板、卡通模式）走 上传→转换→精修→烫染预览→导出 全流程，产出图纸与样图并排对照。
- Q1–Q6 逐项核验（文档 §4.2.2）：色号可追溯（BOM 全量校验）、无抖动（视觉+色数统计）、孤立单格占比 <5%（卡通类）、轮廓可读（对照目测）、版式一致、色彩还原（屏显 vs 色卡 RGB）。
- 性能实测：转换 ≤2s（104×104×291 色）、绘制 ≤100ms、撤销即时、烫染切换 ≤1s / 缩略图 ≤3s / 强度防抖 150ms、自动保存不阻塞、效果封面保存 ≤500ms 返回。
- 兼容抽查：近两年主流 Chrome / Edge / Safari / Firefox（Canvas 2D 能力面）。
- 产出物：P0 验收报告（逐项结论+截图/数据）+ M7 优先级建议清单 + 遗留问题清单。

## Acceptance Criteria

- [ ] 父任务 prd.md 五条跨子任务验收标准全部通过并留证
- [ ] Q1–Q6 逐项有证据（脚本统计或对照截图）
- [ ] 性能指标有实测数据（非估算）
- [ ] 验收报告落档 `.trellis/tasks/本任务/` 并同步父任务

## Notes

- 依赖：M3/M4/M5 全部归档后启动。
- 前置素材：用户样图（55×63 MARD）或同类替代图、烫染实物对照图——不齐则先向用户索取。
