## B · 品牌色号系统（m1 算法层）

| 功能 | 状态 | 详细描述 |
| --- | --- | --- |
| B1 色板数据库 | ✅ | 五品牌 1,386 色构建期内置 `src/data/`（MARD 291 / COCO 293 / Perler 103 / Hama 92 / Artkal 四系 607），CSV 数据源 beadcolors（MIT），全生态唯一权威副本，入库校验色号唯一 |
| B2 特殊效果色 | ✅ | 珠光/夜光/UV/果冻色带 `colorType` 标记，默认不参与自动匹配（RGB 不代表实观感），但可手动选用——对齐"不限制色号使用"口径 |
| B3 色彩科学 | ✅ | sRGB→CIELAB→CIEDE2000 色差计算（感知均匀，暗色/黄色区不失真）；跨品牌近似色计算复用同一函数 |
| B4 色板面板操作 | ✅ | （UI 在 m2 交付）按色号/名称搜索、按色系分组浏览、最近使用记录 |
| B5 色数口径 | ✅ | 无硬性色数上限，降色工具与档位均为建议非门槛；BOM 行预留 `brand/code/count` 字段供 P1"色号=商品=权益费率"映射 |
| B6 排除色号 | ➖ | P1：从转换匹配候选中剔除不想用的色号（与 targetColors 互补，Beadify 调研采纳项 9） |
| B7 库存感知色板 | ➖ | P1+：转换前勾选已有豆色、围绕库存过滤色板（对齐需求 §5.3 豆库，需账号体系，Beadify Stash） |

## C · 创作入口与图片转图纸（m1 管线 + m3 流程）

| 功能 | 状态 | 详细描述 |
| --- | --- | --- |
| C1 新建对话框 | ✅ | 两条路径：①"空白画布 / 导入我的作品"（合并入口——导入图片自动挂到参考层后进编辑器）；②"从图片转图"（进转换流程）。编辑器内随时可发起转换，入口只是起点 |
| C2 新建参数三选 | ✅ | 规格（5mm/2.6mm）、板型（档位 29/52/58/87/104 + 自定义 7–104 正方形；非正方形 P1 再开）、品牌色卡三选；创建后品牌锁定 |
| C3 六步转图流程 | ✅ | 上传（拖拽/选择，PNG/JPG/WebP ≤10MB，透明背景，预压缩 2048）→ **裁剪与类型**（8 向手柄裁剪框+主体缩放+实时豆宽预估；源图类型三选：普通/像素画/拼豆图纸）→ 选生成类型 → 转换调参（左侧原图、右侧结果实时对照）→ 进编辑器精修（原图挂参考层）→ 导出（pixel-beads 调研采纳） |
| C4 生成类型预设 | ✅ | 用户选"作品的样子"而非参数：Q版（20×20–29×29，色数默认 16 可调可关，卡通风格）/ 标准（29×29–58×58，卡通，默认档）/ 写真（58×58–104×104，平滑，色数不限）；所有预置参数在第③步均可覆盖 |
| C5 转换参数面板 | ✅ | 目标尺寸（档位+自定义）、品牌、平滑/卡通、目标色数（targetColors，含 24/48/72/96/120/不限 档位 chips，pixel-beads 调研采纳）、亮度/对比度/饱和度、移除纯色背景（容差可调） |
| C6 转换管线（算法） | ✅ | 阶梯式减半+区域平均降采样 → 双模式代表色（平滑=区域平均 / 卡通=量化取众数，保硬边不染灰）→ CIEDE2000 最近色匹配 → 默认无抖动 → targetColors 色板子集聚类 → 量化 5bit 缓存（典型素材 <200ms）→ Alpha 直通+边缘扩散式背景移除；104×104 计算走 Web Worker |
| C7 边界提示 | ✅ | 低分辨率（<100×100）与近纯色图片提示更换；Q版+写实照片提示改用写真或裁剪主体；超过 104×104 拒绝并说明（P2 大图分区承接） |
| C8 源图类型直映 | ✅ | 源图为像素画/已有拼豆图纸时按格 1:1 映射最近色号，不走降采样，避免二次失真（pixel-beads 调研采纳） |

## E · 烫染效果预览（m4-finish）

滤镜范式（对标修图 App）：一排预设缩略图、单击应用、强度滑杆、按住对比——用户选的不是参数，是成品的样子。

| 功能 | 状态 | 详细描述 |
| --- | --- | --- |
| E1 效果面板 F1 | 🔶 | 编辑器内预设缩略图列表（用当前作品低分辨率实时渲染小样）+ 烫法名 + 分组（经典/质感/闪亮）；面板首次打开 ≤3s，缩略图逐个替换不阻塞 |
| E2 画布实时渲染 F2 | 🔶 | 点选烫法后画布即时切换烫后效果，隐藏网格与色号标注，Esc 返回编辑视图；**零副作用**——效果是渲染层属性，永不修改 cells |
| E3 强度调节 F3 | 🔶 | 0–100% 滑杆，表面结构/色彩偏移/光泽同系数插值；拖动停顿 150ms 后重渲染，完成 ≤1s |
| E4 对比查看 F4 | 🔶 | 按住"对比"按钮或空格键，瞬时切回未烫的平面图纸 |
| E5 保存与效果封面 F6 | 🔶 | `finish{preset,intensity}` 写入工程 JSON；保存动作 ≤500ms 返回，效果封面（全分辨率 PNG）异步生成，失败降级用平面图纸图不阻塞保存 |
| E6 六种预设渲染 | 🔶 | 正常烫/毛巾烫/格利特烫/亮片烫/华夫格烫/搓澡巾烫；Canvas 2D 逐像素管线（熔融基底→高度场→法线光照→烫法特效→色调映射）在 Worker 执行；单预设切换 ≤1s 不冻结 UI；视觉以实物照片对照调优验收 |
| E7 工艺参数卡 F5 | ⏸ | 每烫法的垫材、撕取时机、镜像提示、温度注意、深浅色建议 |
| E8 分享图导出 F7 | ⏸ | 竖版分享图：上半效果渲染 + 下半信息条（标题/格数/色数/豆数/烫法） |
| E9 单面无孔/褶皱烫 | ➖ | P2：规格预定义，暂不实现 |
| E10 图库展示联动 F8 | ➖ | P1：作品卡默认用效果封面，详情页"图纸/效果"切换 |
| E11 材料推荐入口 F9 | ➖ | P2：工艺卡上的垫材商城入口 |
